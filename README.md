## Overview
This repository contains the assignments for the Compilation course (10334) taken during the Summer 2026 semester. The project involves building lexical analyzers and parsers for processing and validating exam text files using `flex` and `bison` in C/C++.

---

## Assignment 1: Lexical Analyzer (Flex)
**Status:** Completed ✅

In this assignment, we implemented a lexical analyzer using `flex`.
- **Goal:** Scan and identify tokens from an exam input file format.
- **Functionality:** 
  - Reads input containing questions, sections, and their respective scores.
  - Recognizes tokens: `QUESTION`, `NUM`, `TOPIC`, `SECTION`, `SCORE`.
  - Prints a list of recognized tokens and their corresponding lexemes.
  - Validates that the total score of all sections adds up exactly to 100.
  - Handles lexical errors and reports the specific line and invalid character using `yylineno`.
- **Main Files:** `ex1.lex`, `input1`, `output1`.

## Assignment 2: Parsers (Top-Down & Bottom-Up)
**Status:** Completed ✅

In this assignment, we built two types of parsers that receive tokens generated by the `flex` scanner. The grammar was expanded to include an overarching `EXAM` token.
- **Goal:** Parse the exam file's structure and perform semantic analysis.
- **Implementations:**
  1. **BottomUp:** Developed using `bison`.
  2. **TopDown:** Developed as a custom Recursive Descent Parser.
- **Functionality:**
  - Analyzes the grammar structure of the exam document.
  - For each question, prints the question number, topic, and the total score of its sections.
  - Validates that the sum of scores across *all* questions equals 100.
  - Utilizes semantic values (`yylval` union) passed from `flex` to the parsers for mathematical accumulations.
- **Directory Structure:**
  - `/BottomUp/` - Contains the `flex` file, `bison` file, `makefile`, and I/O examples.
  - `/TopDown/` - Contains the `flex` file, custom recursive descent parser, `makefile`, shared tokens header, and I/O examples.
